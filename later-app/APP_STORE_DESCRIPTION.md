# LATER: AI Coach That Gets You Out of Tutorial Hell

## Description
Stop saving tutorials. Start building projects.

LATER is your AI learning coach that:
- Analyzes your Learning DNA (when you learn, how long you focus, why you quit)
- Creates a personalized 90-day plan AROUND your DNA
- Tells you what to build TODAY (no more decision fatigue)
- Intervenes when you're stuck (before you quit)
- Generates starter code tailored to your skill level

## Features
✅ Personalized 90-day roadmap  
✅ Daily building tasks with time estimates  
✅ AI intervention when you save without shipping  
✅ Progress tracking & streak gamification  
✅ Complete starter code with line numbering for every project  
✅ Offline support (all 90 projects cached locally)  
✅ Dark mode & custom theme support  
✅ Push notifications & morning reminders  
✅ Achievement trophy case & global leaderboard  
✅ 1-tap progress sharing to social networks
